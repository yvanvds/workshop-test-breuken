Arcadia-logo (beeldmerk + woordmerk ARCADIA). `arcadia-logo.svg` is het origineel: groen `#76B82A`, letters `#333534`, voor lichte grond (`bg`, `surface`). `arcadia-logo-dark.svg` is afgeleid: letters `#EAF2E3` voor donkere grond — laten bevestigen door de communicatiedienst. Toon ze met `.ai-logo--light` / `.ai-logo--dark`. Hoogte 24–30px in balken; vrije ruimte rondom minstens de hoogte van de A.
