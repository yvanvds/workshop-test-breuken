# SectionHeader

Kop boven een blok inhoud: eyebrow, `<h2>` en optioneel een zin uitleg of een link rechts.

**Wat jij levert:** een `.ai-section-head` met `.ai-eyebrow` (hoofdletters via CSS), een `<h2>` en optioneel een `<p>`. Met `ai-section-head--split` staat een actie rechts naast de titel.

De eyebrow is `brand-text`. Voor secties over AI gebruik je `.ai-eyebrow--ai` (teal).
