# SiteHeader

Bovenbalk van een pagina: Arcadia-logo, optioneel een teal label en een menu.

**Wat jij levert:** een `.ai-header` > `.ai-header__inner` met:
- `a.ai-header__brand` met de logo's (`.ai-logo--light`, `.ai-logo--dark`, zie `assets/Logos/`) en optioneel `.ai-header__tag`;
- `nav.ai-header__nav` met `aria-label`, en `aria-current="page"` op het actieve menu-item.

Het label `.ai-header__tag` draagt de teal knoop uit het netwerkmotief. De tekst kies je zelf.
