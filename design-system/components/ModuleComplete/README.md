# ModuleComplete

Afsluiter van een reeks stappen: een beeld, een titel, een lijst met wat er bereikt is en de weg verder.

**Wat jij levert:** een `.ai-complete` met:
- een `img.ai-complete__mark`, bijvoorbeeld de AI-barometer of een niveau-icoon uit `assets/AI-barometer/`;
- een `<div>` met een `<h2>`, een `ul.ai-complete__list` (elke `<li>` met een vinkje `svg.ai-icon` en tekst) en knoppen in een `.ai-row`.

Onder 520px schuift het beeld boven de tekst.
