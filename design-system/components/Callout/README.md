# Callout

Kader om een tip, uitleg of waarschuwing te laten opvallen.

**Wat jij levert:** een `.ai-callout` met variant, een icoon (`<svg class="ai-icon">`) en daarnaast een `<div>` met `.ai-callout__title` en tekst.

| Variant | Wanneer |
|---|---|
| standaard (`surface-sunken`) | Tip, geheugensteun. |
| `ai-callout--ai` | Uitleg over hoe AI werkt. Teal = AI. |
| `ai-callout--warning` | Iets waar je op moet letten, zoals privacy of verzonnen feiten. |
